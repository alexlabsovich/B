# DeadWeb Bot

Telegram-бот для создания контента и мониторинга каналов. Работает только
с пользователем, чей Telegram ID указан в `ALLOWED_USER_ID`.

## Возможности

- **Content** — генерация постов через OpenRouter (модель
  `inclusionai/ling-3.0-flash-fin:free`). Запрос можно дополнить пунктами:
  1. Пример поста
  2. Нужен ли поиск в интернете
  3. Сохранять ли стиль оригинала
  4. Дополнительные заметки

  Любой из пунктов можно не указывать — на разбор остальных это не влияет.
- **Каналы** — листаемый (стрелки ⬅️ ➡️) список отслеживаемых каналов с
  аватаркой, ссылкой, числом подписчиков и просмотрами последнего поста.
  Данные собирает отдельный Telegram-аккаунт (юзербот), добавленный
  администратором в каждый канал; обновление — раз в сутки.
- Предыдущее сообщение бота удаляется при каждом новом запросе.

## Установка

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

1. **BOT_TOKEN** — создайте бота через [@BotFather](https://t.me/BotFather).
2. **ALLOWED_USER_ID** — ваш Telegram ID (уже стоит `8373993954`).
3. **OPENROUTER_API_KEY** — ключ с [openrouter.ai/keys](https://openrouter.ai/keys).
4. **TELEGRAM_API_ID / TELEGRAM_API_HASH** — получите на
   [my.telegram.org](https://my.telegram.org) → "API development tools".
   Это данные не бота, а **обычного Telegram-аккаунта**, который должен
   быть администратором во всех отслеживаемых каналах (чтобы можно было
   получить число подписчиков, просмотры и т.д.).

## Первый запуск

```bash
python main.py
```

При самом первом запуске Telethon попросит в консоли номер телефона и код
подтверждения того аккаунта, который будет парсить каналы. После этого
рядом с проектом появится файл `userbot_session.session` — при следующих
запусках повторная авторизация не потребуется.

## Добавление каналов для мониторинга

Аккаунт из `TELEGRAM_API_ID/HASH` должен быть добавлен **администратором**
в канал. После этого в чате с ботом (от имени `ALLOWED_USER_ID`) выполните:

```
/addchannel @username_канала
```

Убрать канал из отслеживания:

```
/removechannel @username_канала
```

Данные по каналам обновляются автоматически раз в 24 часа, а также сразу
при добавлении канала.

## Структура проекта

```
deadweb_bot/
├── main.py                     # точка входа
├── config.py                   # конфигурация из .env
├── filters.py                  # фильтр «только разрешённый пользователь»
├── keyboards.py                # reply/inline клавиатуры
├── storage.py                  # json-хранилище + последнее сообщение бота
├── handlers/
│   ├── common.py                # /start
│   ├── content.py                # раздел Content (генерация постов)
│   └── channels.py               # раздел Каналы (листание, /addchannel)
├── services/
│   ├── openrouter_client.py      # запросы к OpenRouter
│   ├── search.py                 # веб-поиск (DuckDuckGo, без API-ключа)
│   └── telethon_client.py        # юзербот для парсинга каналов
└── data/
    ├── channels.json             # кэш данных по каналам (создаётся сам)
    ├── tracked_channels.json     # список отслеживаемых каналов
    └── avatars/                  # скачанные аватарки каналов
```

## Примечания

- Поиск в интернете (пункт 2 в Content) реализован через
  `duckduckgo-search` — бесплатно, без API-ключа. При желании можно
  заменить на другой поисковый сервис в `services/search.py`.
- Модель `inclusionai/ling-3.0-flash-fin:free` — бесплатная, у OpenRouter
  могут быть ограничения по частоте запросов для free-моделей.
